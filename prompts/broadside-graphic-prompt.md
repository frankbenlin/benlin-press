# Broadside Graphic Prompt

Design a broadside informational graphic for Benlin Press that communicates the principles of accessible publishing and public authorship.

Core ideas:
- Open publishing systems
- Shared authorship
- Print-ready outputs
- Community access to information
- Everyday tools for public communication

Visual direction:
- Crisp layout with strong hierarchy
- Use a calm editorial palette
- Keep the message readable from a distance
- Prioritize clarity over complexity

Output format:
- poster-like single-sheet graphic
- simple explanatory labels
- bold key phrases
- print-ready composition
