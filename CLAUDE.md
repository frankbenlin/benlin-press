# Benlin Press

Project goal:
Build a small publishing app for Benlin Press with:
- an 8-page two-span zine
- a broadside informational graphic
- a contact form
- an editorial, calm, premium visual aesthetic

Core principles:
- Keep the project lightweight and static unless otherwise requested.
- Use the repo as the source of truth.
- Maintain a consistent editorial brand.
- Favor accessible design and print-first thinking.
- Respect the existing project structure and avoid unnecessary rewrites.

Working style:
- Read the current project files before making changes.
- Prefer small, intentional updates that improve clarity and usability.
- Keep content grounded in the Benlin Press mission: freedom of the press exists when everyone becomes the press.
- When generating visual or writing work, aim for thoughtful, readable, and public-facing output.

Files of interest:
- README.md — project overview
- index.html — main app and landing page
- styles.css — visual system and layout
- app.js — interactive behavior

Prompt library:
- See `/prompts/` for reusable writing and publishing prompts
- See `/docs/` for additional project guidance, brand references, and print-oriented workflow notes

When working on this repo:
1. Understand the current state before making changes.
2. Keep updates minimal and intentional.
3. Prefer readability, clarity, and a strong print/editorial identity.
4. Keep all work GitHub-ready.
